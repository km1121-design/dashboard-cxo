## 3. システムアーキテクチャ & 技術スタック

```
[フロントエンド: Web アプリ (Next.js / Vite + React)]
  ├─ 1. 日別進捗 (Daily Progress)   - 当日案件ログ・日割り目標達成率
  ├─ 2. 月別結果 (Monthly Results)  - 当月給与見立て・事業部損益PL
  ├─ 3. 総結果 (Annual / Total)     - 第5期通期12ヶ月利益・年収シミュレーション
  └─ 4. 📱 BARROOTS 日報入力 ＆ LINE転送モーダル
        │
        │ (HTTP GET / POST JSON)
        ▼
[バックエンド: Google Apps Script (GAS Web API)]
  └─ Code.gs (doGet / doPost でデータ追加・取得)
        │
        ▼
[データストア: Google Sheets]
  ├─ t_sales   (日報・売上ログシート)
  └─ m_members (メンバーマスタ)
```

- **フロントエンド**: React (TypeScript), Tailwind CSS, Lucide Icons
- **バックエンド API**: Google Apps Script (GAS) Web App (Code.gs)
- **データフォーマット**: JSON

## 5. 各事業部の計算ロジック

### 5.1 イベント営業事業部（責任者: 入舩 雄志）

**実質PL売上**:
商材カテゴリが「転職支援」の場合、売上の **50%** のみを計上。その他は100%。

**営業利益**:

```
営業利益 = 実質売上 − 経費 − 基本給(32万) − 三田氏保守管理費(2万)
```

**当月吐き出しインセンティブ**:
当月営業利益 **≧ 1,000,000** 円の場合、当月の「店舗運営(BAR)」売上総額の **10%** を翌月末に支給。100万円未満の場合は **0** 円。

**半年ボーナス積立（プール金）**:

```
月次プール額 = max(0, (営業利益 × 10%) − 当月吐き出しインセンティブ)
```

### 5.2 人材事業部（責任者: 中原 聖人）

**営業利益**:

```
営業利益 = 売上 − 直接経費(広告/コンサル費等) − 基本給(35万) − 概算固定費(10万/人) − 三田氏保守費(2万)
```

**決定手当**:
広告経由決定: 10,000円 / 件、リファーラル決定: 30,000円 / 件

**個人PL 15% 還元**:
個人PL利益の **15%** を還元。

**事業部チームインセンプール**:
利益目標達成まで **3%**、目標超過分には **5%** を適用してプール。

**他部紹介 (クロスセル)**:
BAR顧客紹介（10万円以上）: 店舗売上の **10%** を個人PLに還元。

### 5.3 物流・バックヤード（責任者: 三田 航大）

- **固定報酬**: 月額 400,000円
- **内訳**: 物流固定費 ＋ 営業部(2万) ＋ 人材部(2万) ＋ 本部(1万) の保守費を徴収充当。

## 6. BARROOTS 店舗日報 ＆ LINE転送フォーマット

店舗「BARROOTS」の日報入力時、以下のフォーマットに準拠してLINE転送テキストを自動生成する。

```
日付  8/12（水）
月目標 360,000円
当日売り上げ  15,000円
内訳
└現金  15,000円
└クレカ 0円
└電子マネー 0円
└QR  0円
来客数  4組  8名
内訳
└新規  8名
└既存  0名
当月累計売上  15,000円
残営業日 17日
1日必達  20,300円
新規累計  8名
『総評』
急遽オープンの為準備何もしていなかったが、持ち前のカウンタースキルで皆を笑顔に出来きました✨️
```

### 自動計算ロジック

- **当日売り上げ**: 現金 + クレカ + 電子マネー + QR
- **当月累計売上**: 前日までの累計売上 + 当日売り上げ
- **1日必達**: `⌈(月目標 − 当月累計売上) ÷ 残営業日⌉`
- **新規累計**: 前日までの新規累計 + 本日新規人数

## 8. テスト・運用注意点

**CORSおよびGASリダイレクト注意**:
アプリからGASへのPOST送信時は `mode: 'no-cors'` または GAS側でのContentServiceレスポンスリダイレクト処理を考慮すること。

**スプレッドシートアクセス権限**:
GASデプロイ時の「アクセスできるユーザー」は必ず **「全員 (Anyone)」** に設定すること。
